# ABU2024_R2_img-recog

これはNHK学生ロボコン2024において、R2ロボットに実装した画像認識部分に関するリポジトリです。

本リポジトリには、私が担当・実装したコード・ファイルのみを掲載しています。

本リポジトリは、YOLOv8によるカラーボール認識と、ROSノード間通信を介したデータ送受信を中心に構成されています。

[主な内容]

・src：実際にR2ロボットに導入したディレクトリ

　・r2_ball_recog-s：外部のカゴに入ったボールの配置を認識するディレクトリ

  　　・r2-ball-recog-s.py：YOLOv8でカラーボールの配置を検出し、認識したボールの配置に応じてROSトピックへパブリッシュ

   　・r2-ball-recog-s.cpp：サブスクライブしたノードを別のトピックへパブリッシュ
 
　・r2_ball_recog：機体内に取り込んだボールの認識を行うディレクトリ

 　　・r2-ball-recog.py：YOLOv8でカラーボールを検出し、認識した各ボールに応じてROSトピックへパブリッシュ

   　・r2-ball-recog.cpp：サブスクライブしたノードを別のトピックへパブリッシュ

・previous：テスト段階で用いたディレクトリ

※ CMakeLists.txtおよびpackage.xmlは、ROSノード（PythonおよびC++）の依存関係と構成を定義したファイルであり、私が実装した画像認識ノード群（YOLOv8 + ROS通信）をビルド・実行するための設定として作成しました。
